### 📲 PAIRING INSTRUCTIONS

1. Open the ADEZ MD pairing page.
2. Enter your WhatsApp number with the correct country code.
3. Generate your pairing code.
4. Open WhatsApp on your phone.
5. Go to **Settings → Linked Devices**.
6. Select **Link a Device**.
7. Choose phone-number linking if available.
8. Enter the pairing code displayed on the website.

Follow the instructions provided by the pairing website.

> 🔒 **Security:** Never share your pairing code or authentication session with anyone. Only link your WhatsApp account through a service you trust.

## 📱 INSTALL ADEZ MD ON TERMUX

### STEP 1: UPDATE TERMUX

```bash
pkg update && pkg upgrade -y
```

### STEP 2: INSTALL REQUIREMENTS

```bash
pkg install nodejs git -y
```

### STEP 3: CLONE THE REPOSITORY

```bash
git clone https://github.com/adeztech2/adez-md.git
```

### STEP 4: OPEN THE PROJECT FOLDER

```bash
cd adez-md
```

### STEP 5: INSTALL DEPENDENCIES

```bash
npm install
```

### STEP 6: START THE BOT

```bash
npm start
```

Follow the instructions displayed in the terminal.

> **Note:** These commands assume the repository contains a valid `package.json` with a working `start` script.
